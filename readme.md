== Description ==

PrimeUI Widgets adds a PrimeUI category in Elementor. Every widget includes design, color, type, spacing, columns, and shadow controls.

== Installation ==

1. Upload the `primeui` folder to `wp-content/plugins/`.
2. Activate PrimeUI Widgets for Elementor.
3. Edit a page with Elementor and open PrimeUI.
