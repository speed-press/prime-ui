Free Elementor widgets to help you build beautiful WordPress pages with flexible styling controls. Not affiliated with Elementor.

== Description ==

PrimeUI Widgets for Elementor adds a dedicated PrimeUI category to the Elementor editor, making it easier to build and customize page layouts.

The plugin provides Elementor widgets with styling options that help you control the appearance of your content directly from the editor, without needing to write custom CSS for every design adjustment.

Whether you are creating a business website, landing page, portfolio, or blog, PrimeUI helps you customize your layouts using familiar Elementor controls.

= Key Features =

* Dedicated PrimeUI widget category inside Elementor.
* Flexible design and styling controls.
* Color customization options.
* Typography controls.
* Spacing and layout adjustments.
* Column configuration options.
* Shadow controls for visual styling.
* Visual editing through the Elementor interface.
* Works within the WordPress and Elementor editing workflow.

Note: Available widgets and controls depend on the features included in the installed version of the plugin.

== Installation ==

1. Make sure WordPress and Elementor are installed and activated.
2. Upload the plugin ZIP file through Plugins > Add New Plugin > Upload Plugin, or upload the extracted plugin folder to /wp-content/plugins/.
3. Activate PrimeUI Widgets for Elementor from the Plugins screen.
4. Open a page using Elementor.
5. Find the PrimeUI category in the Elementor widget panel.
6. Add a widget to your page and customize its available settings.

== Frequently Asked Questions ==

= Does PrimeUI work without Elementor? =

No. Elementor must be installed and activated for the plugin's Elementor widgets to work.

= Is PrimeUI affiliated with Elementor? =

No. PrimeUI is an independent plugin and is not affiliated with or endorsed by Elementor.

= Can I customize widget styles? =

Yes. Widgets provide styling controls for supported options such as colors, typography, spacing, columns, and shadows.

= Do I need to write CSS? =

You can customize the supported settings through Elementor without writing CSS. Custom CSS may still be useful for advanced designs.

= Where can I find the widgets? =

Open the Elementor editor and look for the PrimeUI category in the widget panel.
